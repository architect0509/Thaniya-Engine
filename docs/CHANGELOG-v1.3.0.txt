Thaniya-SoundLab 업데이트 로그
========================================
버전 : v1.3.0
날짜 : 2026.11.26
요약 : 응애모드 · 전체 무한반복 · 로딩 화면 · 펜 미리보기


[새 기능]

1. 응애모드 (baby/index.html)
   - 칸을 톡톡 누르면 노래가 되는 아주 쉬운 작곡 모드예요. (크롬 뮤직랩 Song Maker 방식)
   - 위쪽 칸 = 멜로디(두 옥타브, 음마다 무지개색), 아래 두 줄 = 북 소리(동그라미 큰북 · 세모 작은북)
   - 누르면 넣기, 다시 누르면 빼기, 끌면 여러 칸을 한 번에 칠하거나 지워요.
   - 아래 막대: 재생/멈춤 · 되돌리기 · 악기 · 북 소리 · 무한 반복(기본 켜짐) · 빠르기(60~180)
   - 악기 4종: 피아노 · 마림바 · 신스 · 플루트
   - 북 소리 4종: 드럼 · 전자 · 나무 · 콩가
   - 설정 시트: 노래 이름 · 길이(1~8마디) · 음계(도레미 / 아무렇게나 예쁘게) · 음 높이(낮게/보통/높게)
   - 내 노래: 저장 · 불러오기 · 지우기 · 새 노래 (이 브라우저에 자동 저장)
   - MIDI 파일로 내보내기 → 스튜디오 마이페이지 「불러오기」로 열어서 이어서 다듬을 수 있어요.
   - iOS 느낌의 간단한 화면: 둥근 카드 · 유리 질감 아래 막대 · 아래에서 올라오는 시트
   - 휴대폰 화면에 맞춘 배치, 손가락으로 누르기 쉬운 칸 크기, 다크 모드 자동 적용
   - 응애모드만 따로 홈 화면 앱으로 설치할 수 있어요. (baby/manifest.webmanifest)
   - 스페이스 = 재생/멈춤, Ctrl+Z = 되돌리기

2. 모드 전환
   - index: 「어떤 모드로 시작할까요?」 섹션(스튜디오 / 응애모드), 위쪽 메뉴의 응애모드 버튼,
     설치 섹션의 「응애모드만 설치」
   - 마이페이지: 「새 곡 만들기」를 누르면 스튜디오 / 응애모드 중에서 골라요.
   - 편집 화면: 설정 › 일반 › 「응애모드 열기」
   - 응애모드에서는 왼쪽 위 뒤로 버튼이나 설정 › 「스튜디오 모드로 전환」으로 돌아가요.

3. 전체 무한반복
   - 단축키 Shift+L, 하단 재생 막대의 ∞ 버튼 (모바일은 더보기 › 재생 · 녹음)
   - 곡 끝(마디 끝까지)에 닿으면 처음부터 끊김 없이 계속 반복해요.
   - 반복 구간(L)이 켜져 있으면 반복 구간을 먼저 따라요.
   - 켜고 끈 상태는 모든 곡에 공통으로 저장돼요.
   - 설정 › 단축키에서 다른 키로 바꿀 수 있어요.

4. 로딩 화면 (loader.js)
   - 화면을 열 때와 다른 화면으로 넘어갈 때 로고 · 움직이는 막대 · 팁 문구가 있는 로딩 화면이 떠요.
   - 편집 화면 · 마이페이지는 필요한 스크립트를 다 불러온 뒤에 닫혀요.
   - 다운로드나 나가기 취소로 화면에 남으면 몇 초 뒤 저절로 닫혀요.

5. 펜 미리보기
   - 펜 도구로 보드 위를 움직이면 누를 때 노트가 생길 자리를 투명한 회색 노트로 보여 줘요.
   - 이미 있는 노트 위, Ctrl(⌘)을 누른 상태, 터치 화면에서는 보이지 않아요.


[바뀐 점]

- 폴더 정리: 스크립트는 js/, 스타일은 css/, 변경 기록은 docs/ 폴더로 옮겼어요.
  (index.html · edit.html · mypage.html · humming-composer.html · sw.js 는 맨 위에 그대로)
- 마이페이지: PC에서 곡 목록이 4열로 보여요. (1100px 이하 3열, 모바일 2열)
- 아이콘 정리: 이모티콘을 모두 선 아이콘(SVG)으로 바꿨어요.
  · 응애모드 표시는 네모 4칸 아이콘 + 분홍~주황 배지로 통일
  · 악보 창의 스피커 표시, 튜토리얼 마지막 문구도 이모티콘 없이 바꿨어요.
- 오프라인 저장본에 loader.js · 응애모드 파일을 추가했어요. (sw.js)
