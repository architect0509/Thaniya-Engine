HOW IT WORKS

세 단계면 한 곡

01

녹음하거나 그리기

Shift+R로 녹음하거나 펜 도구로 노트를 직접 찍어요.

02

반주와 비트 얹기

J를 누르면 추천 반주 · 샘플 반주 · 비트를 골라 바로 들어볼 수 있어요.

03

저장하고 내보내기

자동 저장은 기본, 마이페이지에서 프로젝트 파일이나 MIDI로 내보내요.

INSTALL · PC

컴퓨터에 설치해서 사용하세요

설치하면 브라우저 탭 없이 앱 창으로 바로 열리고, 인터넷이 없어도 열립니다. 새 버전이 나오면 프로그램에서 알려 드려요.

Linux용 내려받기
Chrome · Chromium · Edge에서 설치

처음 실행할 때 보안 경고가 뜨면 Windows는 ‘추가 정보 → 실행’, macOS는 Finder에서 앱을 우클릭한 뒤 ‘열기’를 눌러 주세요.

휴대폰에도 설치할 수 있어요. 휴대폰에서 이 사이트를 열고 ‘휴대폰 홈 화면에 설치하세요’에서 설치하면 돼요. 만든 곡은 기기마다 따로 저장되니, 옮길 땐 마이페이지에서 프로젝트 파일로 내보내 주세요.
