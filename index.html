About

만들고, 쓰고, 바로 실행합니다

Thaniya Engine은 유니티 에디터와 비슷한 구조의 작업 화면을 웹에서 그대로 제공합니다. 별도 설치나 가입 없이 열자마자 시작할 수 있어요.

설치 없는 웹 에디터브라우저만 있으면 어디서든 열고, 작업 내용은 이 브라우저에 저장됩니다.
익숙한 편집 구조계층 구조, 인스펙터, 프로젝트, 콘솔 패널을 드래그해 원하는 자리에 도킹할 수 있습니다.
C# 기반 스크립트Unity 스타일의 C# 문법으로 오브젝트를 움직이고, 학습 창에서 바로 연습합니다.
Learning

엔진 안에서 C#을 배워요

Thaniya Engine의 화면 사용법과 C# 스크립트를 짧은 문제로 하나씩 익혀요. 카드를 눌러 바로 시작하세요.

짧은 문제로 한 걸음씩타일맵, 게임 오브젝트, 콘솔 출력, 컴포넌트에서 주인공 스크립트 · 애니메이션 · 특수 타일 · 씬과 매니저까지 8개 레슨으로 차근차근 익힙니다.
코드 검색코드를 넣으면 쓰인 코드마다 설명과 예시, 예시 출력을 보여 줘요. 진행도나 채점 없이 가볍게 쓸 수 있어요.
진행 상태 확인레슨마다 시작 전 · 진행 중 상태가 표시되고, 학습 기록은 언제든 초기화할 수 있어요.

Features

주요 기능

맵 제작부터 스크립트 작성, 테스트 실행까지 한 화면에서 이어집니다.

01

던전 맵 · 타일 합치기

타일 팔레트로 맵을 그리고, 여러 타일을 겹쳐 새 타일셋으로 저장합니다.

02

C# 스크립트 창

자동완성과 함께 코드를 쓰고 컴포넌트로 붙여 실행합니다. 한글로 쓰는 실험 기능도 있어요.

03

애니메이터 · 애니메이션

상태와 전환, 키프레임 타임라인으로 캐릭터를 움직입니다. 기본 주인공은 걷기 애니메이션이 들어 있어요.

04

오디오 소스 · 매니저

배경 음악과 효과음을 컴포넌트와 Sound 스크립트로 재생하고, 매니저가 씬을 넘어 이어 줍니다.

05

UI 컴포넌트

패널 · 텍스트 · 버튼 · 게이지 바에 토글과 캔버스 그룹을 더해 게임 화면을 꾸밉니다.

06

에셋 스토어 연결

프로젝트 창의 「에셋스토어」에서 무료 타일 · 오브젝트 · 음악을 바로 불러옵니다.

07

패널 도킹 · 레이아웃

패널을 도크에 끌어다 놓거나 떠 있는 창으로 꺼내고, 배치를 JSON으로 저장합니다.

08

콘솔 · 플레이 모드

Debug.Log 출력을 콘솔에서 확인하고, 카메라가 부드럽게 따라가는 게임을 바로 테스트합니다.

09

테마 · 4개 국어

다크 · 라이트 테마와 한국어 · English · 日本語 · 中文을 언제든 바꿉니다.

    무료 에셋을 프로젝트 창에서 바로

    Thaniya Asset Store의 32×32 픽셀 타일과 오브젝트, 반복 재생되는 배경 음악을 엔진 안에서 미리 보고 불러와요. 가입도 결제도 없어요.

    • 45타일
    • 65오브젝트
    • 412조각
    • 14배경 음악
    • 무료모든 에셋
    1. 프로젝트 창의 「에셋스토어」엔진 안에서 스토어 창이 열리고 「엔진과 연결됨」이 표시돼요.
    2. 미리 보고, 들어 보고카드를 누르면 움직이는 미리보기와 음악 파형을 크게 확인할 수 있어요.
    3. 「불러오기」로 프로젝트에저장 위치를 고르면 「에셋 스토어 › 타일 · 사물 · 오디오」 폴더에 들어가고 이 브라우저에 저장돼요.
    엔진에서 불러오기 스토어 둘러보기

    모든 에셋은 무료예요. Thaniya Engine으로 만드는 게임에 자유롭게 넣어 쓸 수 있어요.

    Updates

    최신 업데이트

    엔진에 새로 들어온 변경 사항입니다.

    v11.03-01현재 버전

    씬 · 매니저 · 레슨 8

    학습에 레슨 8 「씬과 매니저」가 생겼습니다. 새 씬을 만들어 포탈로 잇고 시작 씬을 바꿔 보며, 씬이 바뀌어도 살아 있는 BGM 매니저 · 게임 매니저로 음악과 목숨을 이어 갑니다. SceneManager.GetActiveScene · LoadScene · RestartGame도 코드로 익혀요.

    v11.02-03

    룰 타일 · 애니메이션 타일 · 레슨 7

    타일 팔레트에서 타일을 고르면 인스펙터에서 유니티식 룰 타일 · 애니메이션 타일을 만들고 저장해, 타일 선택 창의 「특수 타일」에서 골라 칠합니다. 학습에 레슨 7 「특수 타일」이 생겼고, 타일 칠하기도 Ctrl+Z로 되돌릴 수 있게 고쳤습니다.

    v11.02-02

    에셋 스토어 연결

    프로젝트 창 「에셋스토어」에서 무료 타일 45 · 오브젝트 65 · 배경 음악 14곡을 미리 보고, 고른 폴더로 바로 불러옵니다.

    11.01

    애니메이터 · 애니메이션 창 · 레슨 6

    상태 · 전환 · 조건을 그래프로 편집하고 키프레임 타임라인으로 클립을 만듭니다. 기본 주인공은 걷기 애니메이션이 있는 검은 고양이로 바뀌었고, 학습에 레슨 6 「애니메이션 다루기」가 생겼습니다.

    11.01

    오디오 소스 · 매니저 · 배경 음악

    AudioSource 컴포넌트와 Sound 클래스로 소리를 내고, 씬에 그려지지 않는 매니저가 배경 음악을 이어 줍니다. 기본 배경 음악 「타니아의 아침」이 들어 있어요.

    11.01

    타일 합치기 · 설정 정리

    여러 타일을 무한 격자에 겹쳐 새 타일셋으로 저장합니다. 설정 창은 항목마다 페이지로 나뉘고, 레이아웃을 JSON으로 저장 · 불러올 수 있어요.

    10.30

    다크 · 라이트 테마 · 레슨 5

    모든 화면에 라이트 테마가 생겼고(Ctrl+Shift+L), 레슨 5에서 주인공 이동 스크립트를 직접 만들어 봅니다.

    10.30

    기본 에셋 · UI 컴포넌트 · 카메라

    픽셀 아트 기본 에셋 25종, 토글 · 캔버스 그룹 UI 컴포넌트, 카메라 부드럽게 따라가기가 추가됐습니다.

    10.26

    학습 창 추가

    헤더의 「학습」 버튼으로 에디터 위에 학습 창을 띄워 콘솔 출력 문제를 풀 수 있습니다.
